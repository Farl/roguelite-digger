Asset pack: minipack v5
Workflow: gpt-image-2 CLI (image_gen.py) + custom chroma-key postprocess (postprocess.py)
Model: gpt-image-2, quality=high, background=opaque, size=1024x1024 (worker) / 1024x1536 (tiles)
Art style: pixel-art / premium indie

Worker prompt:
Game sprite sheet, raw source image only. 2x2 grid, exactly 2 columns and 2 rows, on a perfectly flat solid magenta #FF00FF background — no gradients, no shadows, no floor. One miner character per cell, side view facing right, four walk-cycle poses. Full body in every cell: hard hat, face, torso, arms, pickaxe, legs, boots. Character fully contained inside its cell with clear padding. Consistent scale and camera angle across all 4 cells. No overlap across grid lines. No extra objects, no text, no UI, no watermark.

Tile prompt:
Game tile icon sprite sheet. 2 columns × 3 rows grid on a solid magenta #FF00FF background, no gradients, no shadows, no floor, no glow. One centered square tile icon per cell, consistent pixel-art style. Reading left-to-right, top-to-bottom: (1) dirt block, (2) stone block, (3) diamond gem, (4) event rune, (5) puzzle piece, (6) empty crack. Same outline weight, same scale, same perspective for all 6 tiles. No text, no UI, no watermark.

Processing profile:
- worker: 2x2 → 4-frame horizontal strip (256×64), chroma-key threshold=80, LANCZOS resize to 64×64 per frame
- tiles: 2x3 → 6 individual tile_*.png (64×64), chroma-key threshold=80
- postprocess script: assets/sprite-forge/minipack/build_v5/postprocess.py
- outputs published to stable filenames in assets/sprite-forge/minipack for Phaser hot-reload compatibility
